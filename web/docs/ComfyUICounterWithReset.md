# カウンター＆リセットノード

RUN（実行）を押すごとに、数値を自動でカウントアップ、または固定値を出力する便利なノードです

## 📥 入力パラメータ
* **reset_switch (ON/OFF)**:
  * **ON**: `int_box` に入力された数値を出力し、実行後に自動で OFF に切り替わります（リセット機能）
  * **OFF**: 前回出力した数値に `+1` された値を出力します
* **initial_value**: リセット時にベースとなる数値を入力します
* **count_up (ON/OFF)**:
  * **ON**: 通常通りカウントアップします
  * **OFF**: カウントアップを停止し、`int_box` の値をそのまま出力し続ける「固定値モード」になります

## 📤 出力
* **INT**: 現在のカウント数、または固定値
